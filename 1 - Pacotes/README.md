# Comandos

1. Para criar um módulo em GO:
```bash
go mod init <nome-do-modulo>
```

2. Para instalar um módulo:
```bash
go get <nome-do-modulo>
```

3. Para executar um módulo:
```bash
go run <nome-do-modulo>
```

4. Para compilar um módulo:
```bash
go build <nome-do-modulo>
```

5. Para limpar módulos que não estão sendo usados:
```bash
go mod tidy
```
